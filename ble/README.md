# Coyote BLE

This library allows connecting to Coyote devices over Bluetooth Low Energy (BLE). It contains all the raw BLE communication code.

## Library Features
- Discovery of Coyote devices over BLE
    - Coyote v3
    - Coyote v2
    - Pawprints
- Medium-level API for communicating with a Coyote v3 device
    - Read battery level
    - Read device name
    - Read device version
    - Read device serial number
    - Send device command
    - Notifications for Battery level
    - Notifications for Command responses
